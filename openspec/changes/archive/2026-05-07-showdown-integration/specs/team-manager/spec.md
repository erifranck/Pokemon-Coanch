## ADDED Requirements

### Requirement: Team Format Selection
The system SHALL allow users to assign a specific competitive format to each team profile, driving the legality rules for that team.

#### Scenario: Selecting a format
- **WHEN** the user selects a team in the Team Manager
- **THEN** they can choose a format (e.g., "Gen 9 Champions Reg M-A") from a dropdown populated by the generated format definitions.
