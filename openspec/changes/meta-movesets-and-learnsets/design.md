## Context

The move selection currently shows all ~700+ moves from `format.moves` for every Pokémon. The extraction script previously set `allowedMoves: []` because full learnset extraction was deferred. Now we need to properly extract learnsets and filter moves per-Pokémon. Additionally, players need quick access to competitive meta data — popular Pokémon with common sets (moves, items, abilities, natures, EV spreads) — to speed up Threat Matrix population.

## Goals / Non-Goals

**Goals:**
- Extract per-Pokémon legal move lists using `Dex.learnsets` in the update script.
- Filter move dropdowns in `PokemonCard.tsx` and `LiveSimulator.tsx` to the selected Pokémon's learnable moves.
- Create a `MetaSidebar` component showing top meta Pokémon with usage stats and common sets.
- Support one-click "Add to Threats" from the meta sidebar.
- Display "Powered by Pokémon Showdown & Munchstats" credits.

**Non-Goals:**
- Full VGC-legality check for move/ability/item combinations (egg move + ability + item interactions).
- Real-time data updates from Munchstats (use a build-time snapshot).
- Automated natures/EV spreads from usage stats (provide common preset sets).

## Decisions

1. **Learnset Extraction:** Use `formatDex.learnsets.get(speciesId)` in the update script to get all learnable moves. Store as `allowedMoves: string[]` per Pokémon.
   - *Rationale:* Showdown's learnset data is canonical and already filtered by generation.

2. **Munchstats Data:** Fetch the HTML page from Munchstats and scrape the top Pokémon table (name, usage%, common moves/items/abilities). Store as a static JSON snapshot in `src/data/meta_sets.json`, generated by a script or manually curated.
   - *Rationale:* Avoid runtime HTTP calls to external services. A build-time snapshot is sufficient.

3. **Meta Sidebar vs Tab:** Place the meta summary as a collapsible sidebar on the ThreatMatrix page rather than a separate tab. This keeps the workflow tight: see meta → click → add to threats.
   - *Rationale:* The Threat Matrix is where you manage enemy sets; meta data feeds directly into it.

4. **Credits:** Add a small "Powered by Pokémon Showdown & Munchstats" footer in the app layout.
   - *Rationale:* Proper attribution for the data sources.

## Risks / Trade-offs

- **Risk:** Munchstats HTML structure may change, breaking the scraper.
  - *Mitigation:* Manually curate the initial `meta_sets.json` with top 20-30 Pokemon and their common sets. This can be updated periodically.
- **Risk:** Learnset data increases `format_data.json` file size significantly (~100K moves × 328 Pokémon).
  - *Mitigation:* Store only move IDs (strings), not full move objects. Gzip in transit will compress well.
