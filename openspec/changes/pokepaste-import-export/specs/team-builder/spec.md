## ADDED Requirements

### Requirement: Delete Button for Illegal Pokémon
Pokémon cards marked as illegal in the active regulation SHALL display a prominent delete button to allow users to remove them from the team.

#### Scenario: Removing an illegal Pokémon
- **WHEN** a Pokémon card is flagged as illegal (e.g., Charmander in Reg M-A)
- **THEN** the card displays a "Remove Illegal" button alongside the existing "Remove" button.
